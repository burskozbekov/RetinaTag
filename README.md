**Type a description, find your photo.**

Type "sunset over the sea" — find sunset photos. Type "my dog at the beach" — find that exact photo. RetinaTag reads every photo on your machine with local AI (CLIP + Ollama), so search by description like you'd talk.

🔒 **100% offline.** Your photos never leave your device. No cloud, no telemetry, no account required.

## Features

- 🔍 **Local CLIP semantic search** — runs on your machine
- 🤖 **On-device Ollama captions** — natural-language tags
- 👥 **Face clustering** — private, on-device
- 🔐 **Encrypted vault** — PIN + Touch ID / Windows Hello
- 📅 **Year-month timeline** view
- 💾 **USB / SD card import** with EXIF date sorting
- ✅ **Notarized by Apple** for macOS
- 💯 **100% free** — no subscriptions, ever
